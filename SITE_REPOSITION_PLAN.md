# План перепозиционирования сайта retritbest.ru

Дата: 8 ноября 2026.  
Статус: **черновик на согласование. Код и публикация не начаты.**

Сайт сейчас устроен как посадочная одного интенсива в Адыгее. Каталог и страницы Сочи / Владикавказа уже есть, но главная, меню, FAQ, цена, JSON-LD и форма заявки всё ещё говорят только про Адыгею.

Этот документ описывает, **что менять и чего не трогать**. После вашего подтверждения можно переходить к правкам HTML/CSS/JS. Сервер, Caddy, DNS и деплой в этом этапе не трогаем.

### Как добавлять новое направление позже

Уже заложено в проекте, менять архитектуру не нужно:

1. Скопировать `programs/_template.html` → `programs/имя.html`.
2. Заполнить только подтверждённые факты.
3. Добавить карточку и вкладку в `programs.html`.
4. Добавить карточку на главную в блок направлений.
5. Добавить URL в `sitemap.xml`.
6. На странице направления в форму положить скрытое поле `program`.

Новые картинки не генерировать. Если фото локации нет — заглушка «фото появится позже», как у Сочи.

Новые URL вида `/programs/город.html` не создавать в этом этапе, кроме уже существующих.

## 2. Точные изменения по страницам

### 2.1. Главная `index.html`

Сейчас главная — это Адыгея: H1 «Здоровье, красота, молодость и стройность», кикер «17–22 ноября · Адыгея», лента дат 17–22, билет 50 000 ₽, бонус «омоложение», место под Майкопом, FAQ про стоимость интенсива, Event в JSON-LD на `/`, форма в `js/main.js` всегда пишет «Интенсив: 17–22 ноября, Адыгея».

**Предлагаемая структура главной** (визуальный язык тот же: hero, warp, карусель, specular-кнопки, sheet/ink, тест, практика, шар):

| Блок | Что делать |
|---|---|
| Шапка | Пункт «Программы» ведёт на `/programs.html`. «Записаться» — на `#contact`. Якоря Адыгеи (`#place`, `#price`, «Диагностика») с главной убрать из меню. Оставить: Программы, Статьи, подход / тест / практика / заявка. |
| Первый экран | Название бренда как сейчас. Новый H1 и подзаголовок (см. раздел 3). Кикер не про даты Адыгеи, а про бренд, например «авторские выездные программы». Одна главная кнопка: «Смотреть программы» → `/programs.html`. Вторая: «Оставить заявку» → `#contact`. Кнопки «Место / Стоимость» с героя убрать или вести на карточки направлений. |
| Лента дат 17–22 ноября | Убрать с главной. Это календарь конкретной программы, он остаётся на странице Адыгеи. |
| Кому подходят | Переписать текущий `#about` без «этот ретрит» в единственном числе. Смысл из существующих абзацев: напряжение, забота обо всех кроме себя, пауза, внимание к состоянию. Без медицинских обещаний. |

### 2.2. Каталог `programs.html`

- Title, description, H1, lead: только Адыгея и Сочи, без Владикавказа.
- Вкладку и карточку Владикавказа убрать из публичной сетки.
- JSON-LD `ItemList`: два пункта, без `vladikavkaz.html`.
- Кнопка «Записаться» в шапке: не только на Адыгею. Лучше на `/#contact` или на `/programs.html#` с пояснением. На карточке Адыгеи «Подробнее» остаётся.
- Футер: ссылку «Владикавказ» убрать.
- Комментарий «как добавить программу» оставить, он как раз нужен для будущих направлений.
- Вкладку «Архив» оставить: пригодится после завершения Адыгеи, не выдумывая архивных карточек сейчас.

### 2.3. Адыгея `programs/adygea.html`

URL не менять. Страница уже содержит нужные факты: даты 17–22 ноября 2026, под Майкопом, 50 000 ₽, состав, методы, ведущие, проживание, FAQ, форма с `name="program"`.

Что поправить:

- Title / Description короче и согласованы с H1 (раздел 3).
- H1 можно оставить «Ретрит Нового Состояния в Адыгее» — он уже про конкретную программу, не про весь бренд.
- Event JSON-LD оставить **только здесь**, `url` = `https://retritbest.ru/programs/adygea.html`.
- В футере убрать ссылку на Владикавказ.
- Не переносить эти даты и цену обратно на главную как общие условия.
- Даты 17–22 ноября 2026 на момент плана ещё не прошли (сегодня 8 ноября 2026). Когда программа завершится, статус карточки сменить на `closed` / архив — это отдельный шаг, не сейчас.
- Обещания «молодость / стройность / лечение» на этой странице не добавлять. Существующие формулировки про метод Фолля и аппаратные процедуры уже с оговорками — не усиливать их как результат.

### 2.4. Сочи `programs/sochi.html`

URL сохранить.

Сейчас страница честно говорит «уточняется», но много раз повторяет **«ориентировочно весна 2027»**. Это выглядит как факт. Пока владелец это отдельно не подтвердит, в публичных текстах безопаснее писать только «даты, место и стоимость уточняются».

Предлагаемый каркас без искусственного SEO-полотна:

1. H1 направления.
2. Короткий абзац: готовим выездную программу в Сочи в том же авторском подходе.
3. Явный статус: подробности не утверждены.
4. Что уже известно на уровне бренда (психологические, телесные практики и осознанность) — без копирования состава Адыгеи как обещания Сочи.
5. Форма запроса информации.
6. Ссылка на каталог и на Адыгею как на ближайшую подтверждённую программу.

Что убрать или сжать: десять почти пустых секций «для кого / темы / состав / практики / ведущие / место / быт / цена / кадры / FAQ» с одним и тем же «уточняется». Это thin content. Лучше 3–4 коротких блока, чем десять пустых H2.

JSON-LD: оставить `WebPage`, **не** создавать `Event` без дат.

OG-image: сейчас стоит фото Адыгеи. Своих фото Сочи нет и новые нельзя генерировать. Варианты: нейтральный существующий кадр с подписью бренда **или** убрать изображение локации из OG, чтобы не выдавать Адыгею за Сочи. Предпочтение: не подписывать OG как «место в Сочи».

Ссылку на Владикавказ в футере убрать.

### 2.5. Владикавказ — рекомендация вывода из доступа

**Сейчас, после вашего «да» на HTML (без удаления файла):**

1. Убрать карточку, вкладку и ссылки: `programs.html`, футеры `index.html` / `adygea.html` / `sochi.html`, тексты четырёх статей.
2. Удалить URL из `sitemap.xml`.
3. Убрать пункт из JSON-LD каталога.
4. На самой `programs/vladikavkaz.html` поставить `meta robots = noindex, follow` (или `noindex, nofollow`).
5. В `robots.txt` добавить `Disallow: /programs/vladikavkaz.html` **только после** того, как поисковик успеет увидеть noindex. Если закрыть Disallow сразу, робот может не прочитать noindex.
6. Файл не удалять. Редирект не ставить.

**Позже, отдельно, через Timeweb / Caddy (не в этом этапе):**

- Если страница уже есть в индексе: сначала noindex + выпадение из sitemap, затем в Вебмастере «удаление URL».
- Когда индекс очистится: либо 404/410 на этот путь, либо 301 на `/programs.html`, если решите передать вес каталогу.
- Не делать 301 на главную: главная не про Владикавказ.
- Не делать 200 с телом главной (текущий soft 404 сервера как раз это и делает для любых неизвестных путей).

### 2.6. Статьи и 404

- Во всех статьях фразу «Сочи и Владикавказ — ориентировочно весна 2027» заменить на актуальное: ближайшая подтверждённая программа — Адыгея; Сочи — направление, подробности уточняются.
- Статья «Что такое выездная программа»: блок «Сочи и Владикавказ» сузить до Сочи без выдуманного сезона.
- `404.html` и `articles.html` на Владикавказ не ссылаются. Меню «Стоимость» на 404 ведёт на `/#price` — после перестройки главной этот якорь может исчезнуть; лучше вести на `/programs.html`.

## 7. Серверные задачи, которые HTML не решит

Их **нельзя** закрыть этим перепозиционированием. По вашей постановке конфигурацию Timeweb / Caddy / DNS / HTTPS **не меняем**. Список — чтобы не ждать от HTML того, чего он не умеет.

Из `SEO_AUDIT.md` и живой проверки 8 ноября 2026:

| Задача | Почему не HTML |
|---|---|
| Несуществующий URL отдаёт главную с кодом 200 | Live Caddy ведёт себя как SPA (`try_files` → `/index.html`). |
| Настоящий HTTP 404 с телом `404.html` | Нужен `handle_errors` на сервере. Файл `404.html` уже есть, но ошибки его не используют. |
| 301 www → `https://retritbest.ru` | `https://www.retritbest.ru` сейчас пустой 200. Это виртуальный хост Caddy. |
| 301 `/index.html` → `/` | Оба URL отдают 200. |
| Не отдавать `/Caddyfile.example`, `/CADDY_SETUP.md`, `/SEO_AUDIT.md`, этот план | Статика с корня сайта. Либо не класть md в webroot при деплое, либо deny в Caddy. |
| 404/410 для `/programs/vladikavkaz.html` после очистки индекса | Пока только noindex в HTML. Статус ответа меняет сервер. |
| Склейка в Яндекс.Вебмастере / Google Search Console | Кабинеты владельца, не репозиторий. |
| Gzip, TLS, DNS | Хостинг. |

Пока soft 404 жив, поисковик может по-прежнему видеть копии главной на выдуманных путях. Перепозиционирование текстов всё равно нужно: иначе даже каноническая главная спорит с Адыгеей. Но **полный** SEO-эффект будет после серверного этапа, его делаем только по отдельному разрешению.

## Решение, которое нужно от вас

Чтобы перейти к коду, достаточно коротко подтвердить:

2. H1 и подзаголовок главной — как в брифе или иначе.
