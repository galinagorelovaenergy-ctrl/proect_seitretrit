## 2. Нужно ли отдельное согласие

Да. Метрика с Вебвизором и cookie — необязательная аналитика и обработка идентификаторов. По 152-ФЗ это не то же самое, что согласие на заявку в WhatsApp. Сайт не должен запускать счётчик «по умолчанию».

Поэтому:

- до выбора пользователя `tag.js` **не загружается**;
- пиксель `<noscript>` убран: без JavaScript нет возможности спросить согласие, скрытый пиксель его обходил бы;
- выбор хранится в `localStorage` (`nte-metrika-consent`);
- повторно спросить можно из блока «Данные».

Отдельный баннер cookie для «необходимых» технических данных не ставился: страница и так работает без Метрики.

## 3. Как устроен механизм

Новый файл `js/metrika-consent.js` подключён на всех публичных страницах.

| Действие | Что происходит |
|---|---|
| Первый заход | Компактная панель внизу, Метрика не стартует |
| «Принять» | Загружается официальный код счётчика один раз |
| «Отклонить» | Счётчик не грузится, `_ym*`-cookie первого домена сбрасываются |
| Повторный заход | Панель не показывается, действует прошлый выбор |
| Отзыв после «Принять» | Страница перезагружается без счётчика |

Панель в цветах сайта (чернила, лён, медь), без зеркальных кнопок и без перекрытия шапки.

## 4. Защита полей в Вебвизоре

На формах заявки и практик по-прежнему:

- `ym-disable-keys` — не писать клавиши;
- `ym-hide-content` — скрывать содержимое полей в записи.

Это касается имени, телефона, времени звонка, вопроса, желания и страха.

Аналитика форм в кабинете Метрики — настройка интерфейса. Если её включить, будут видны действия с формой, а не текст защищённых полей.
