## Что требует настройки сервера в Timeweb Cloud, а не правки HTML

Эти пункты **не лечатся** изменением `index.html` и других страниц. Пока Caddy на VPS не обновлён, файл `404.html` в репозитории и даже уже залитый `/404.html` **не включаются** для неизвестных адресов.

| Проблема | Где проявляется сейчас | Что сделать на сервере |
|---|---|---|
| Soft 404: любой неизвестный путь = главная, HTTP 200, ~73197 байт | `https://retritbest.ru/no-such-page-audit` | Удалить `try_files {path} /index.html` (или аналог `rewrite` на `/index.html`). Сайт **не SPA**. |
| Нет настоящего HTTP 404 | `/404.html` открывается как обычный файл 200; ошибки сайта всё равно отдают главную | `handle_errors { rewrite * /404.html; file_server }` — тело 404-страницы, **статус остаётся 404**. |
| www не склеен с основным доменом | `https://www.retritbest.ru` → пустой 200 | Блок `www.retritbest.ru { redir https://retritbest.ru{uri} permanent }` |
| HTTP apex уже уходит на HTTPS 308 | `http://retritbest.ru` → `https://retritbest.ru` | Можно оставить (308 для HTTPS нормален). Желательно, чтобы www тоже сразу попадал на HTTPS-apex 301. |
| `/index.html` дублирует `/` | оба 200 | `redir /index.html https://retritbest.ru/ permanent` |
| Служебные md/example отдаются как сайт | `/Caddyfile.example`, `/CADDY_SETUP.md`, `/SEO_AUDIT.md` | Не класть их в `/var/www/retritbest.ru` **или** закрыть `respond 404`. |
| Шаблоны `_template.html` доступны | 200 + noindex | Опционально: `respond 404` на `*_template.html`. |
| `favicon.ico` отсутствует | риск HTML-заглушки | Положить файл или ответить 404, не главной. |
| Gzip | в образце `encode gzip` | Включить сжатие, если на живом сервере ещё нет. |

Рабочий Caddy на Timeweb **не совпадает** с `Caddyfile.example`. Пример в репозитории как раз **без** `try_files` на главную. Пока пример не скопирован в `/etc/caddy/Caddyfile` и не выполнен `caddy reload`, поведение live-сайта не изменится.

DNS: apex и www уже указывают на один IP Timeweb (`178.209.127.53`). Значит, проблема www — в виртуальном хосте Caddy, а не в отсутствии A-записи.
